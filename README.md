# Hundir la Flota

Proyecto web del clásico juego **Hundir la Flota**, desarrollado en equipo utilizando **HTML**, **CSS**, **JavaScript** y **PHP**.  
El objetivo del proyecto es recrear el juego de forma interactiva, con registro de puntuaciones y comunicación entre el cliente y el servidor.

---

## Tecnologías utilizadas

- **HTML5** – estructura y contenido del juego  
- **CSS3** – estilos y diseño visual del tablero e interfaz  
- **JavaScript (app.js)** – control de la lógica del juego en el navegador  
- **PHP (start_game.php, save_score.php, get_scores.php)** – manejo de las puntuaciones y comunicación con el front-end  
- **JSON (scores.json)** – almacenamiento de las puntuaciones de los jugadores  
- **Git / GitHub** – control de versiones y colaboración en equipo  

---

## Funcionalidades principales

- Inicio y reinicio de partida desde el servidor  
- Colocación aleatoria o manual de barcos  
- Turnos dinámicos entre jugador y CPU  
- Detección de impactos y hundimientos  
- Contador de disparos y control de estado del juego  
- Registro y guardado de puntuaciones mediante PHP y JSON  
- Interfaz interactiva y mensajes dinámicos

##  Ejecución del proyecto

1. Clonar o descargar el repositorio del proyecto.  
2. Colocar los archivos en el directorio `htdocs` de **XAMPP** (u otro servidor local con soporte PHP).  
3. Iniciar el servidor **Apache**.  
4. Acceder desde el navegador a: http://localhost/hundir-la-flota/
